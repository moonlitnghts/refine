# Changelog

## Refined visual release — November 2026

- Reworked the visual system around LMAC's existing forest-green, ivory, and warm bronze identity.
- Rebuilt the responsive layout styling for the masthead, hero, service tiles, portfolio, process, contact area, footer, and project galleries.
- Improved typography scale, whitespace, contrast, hover states, and mobile layouts.
- Added a high-priority preload for the homepage hero image.

- Improved reduced-motion handling and scroll-reveal behavior.

- Improved inquiry-form status messaging and error handling while retaining the existing Google Apps Script endpoint and email fallback.
- Preserved the existing pages, project photographs, LMAC logos, domain file, and GitHub Pages-friendly static architecture.

No framework, build step, or package installation is required. Upload the contents of this folder to the repository as usual.
